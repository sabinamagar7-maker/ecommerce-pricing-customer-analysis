#  Brazilian E-Commerce Pricing & Demand Analytics

##  Project Overview

This project presents an exploratory and business-oriented analysis of a Brazilian e-commerce marketplace dataset. The main objective is to analyze pricing behavior, demand trends, revenue drivers, and delivery performance across product categories to generate commercial insights and business recommendations.

The project focuses on understanding how pricing, order volume, and operational factors interact within an e-commerce environment.

The analysis combines:
- Pricing analytics
- Demand analysis
- Revenue analysis
- Delivery and logistics analysis
- Commercial recommendations

using Python, SQL, and exploratory data analysis techniques.

---

#  Business Objectives

The main goals of the project are:

- Analyze category-level pricing patterns
- Understand demand trends and seasonality
- Identify high-revenue and high-volume product categories
- Explore relationships between pricing and demand
- Analyze delivery performance and shipping costs
- Generate business-oriented commercial recommendations
- Build a structured analytical workflow for e-commerce analytics
